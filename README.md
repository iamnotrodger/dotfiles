# dotfiles

Managed with [GNU Stow](https://www.gnu.org/software/stow/).

## tl;dr

| Tool | Purpose |
| --- | --- |
| [zsh](https://www.zsh.org/) | Shell |
| [Neovim](https://neovim.io/) | Text editor |
| [tmux](https://github.com/tmux/tmux) | Terminal multiplexer |
| [Ghostty](https://ghostty.org/) | Terminal emulator |
| [skhd](https://github.com/koekeishiya/skhd) | macOS hotkey daemon |
| [Karabiner-Elements](https://karabiner-elements.pqrs.org/) | Keyboard remapping |
| [k9s](https://k9scli.io/) | Kubernetes TUI |
| [Homebrew](#homebrew) | Package manager (Brewfile) |

## install

```bash
stow .
```
